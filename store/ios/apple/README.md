# 苹果 App Store 渠道（预留，iOS 版未立项）

iOS 版开发启动后准备：

- 开发者账号（$99/年）+ 证书/描述文件管理；包名另定（com.howread.* 系列）。
- TestFlight 内测 → App Store 审核；隐私标签（Privacy Nutrition Labels）、
  跟踪透明度（ATT，若接 AdMob 需 `ATTrackingManager` 弹窗）。
- 发布物：截图（iPhone 各尺寸）、文案 en/zh、App 图标（需与安卓版视觉一致）。
- 引擎：MuPDF 需带 AGPL 声明（同安卓），若做免费版广告再评估 AdMob iOS。
